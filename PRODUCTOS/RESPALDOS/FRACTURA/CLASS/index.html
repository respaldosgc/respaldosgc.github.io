FRACTURA® Class

Modelo Industrial N.º 112746

El Respaldo FRACTURA® Class lleva el concepto de la grieta al diseño de mobiliario. Una composición central que divide visualmente el respaldo y adquiere mayor presencia a medida que aumenta el ancho de la pieza.

Con una altura imponente de referencia de 1,80 metros, fabricación artesanal, estructura reforzada y la posibilidad de incorporar iluminación LED central, FRACTURA® Class está pensado para convertirse en el protagonista del dormitorio.

El concepto Class

La fractura crece con el respaldo.

FRACTURA® Class fue concebido como un sistema visualmente adaptable. A medida que aumenta el ancho de la pieza, la fractura central adquiere mayor desarrollo, manteniendo el equilibrio general de la composición.

El resultado es un respaldo que no se limita a acompañar la cama: construye una pieza protagonista dentro del dormitorio.

Preguntas frecuentes

Preguntas frecuentes sobre FRACTURA® Class

Información sobre el diseño, medidas, iluminación, materiales y fabricación del Respaldo FRACTURA® Class.

¿Qué es el Respaldo FRACTURA® Class?

FRACTURA® Class es un respaldo de cama de diseño caracterizado por una fractura central que divide visualmente la composición. Su diseño puede fabricarse a medida y alcanzar una altura de referencia de 1,80 m.

¿La iluminación LED viene incluida?

La iluminación LED es opcional. La configuración de referencia utiliza iluminación cálida de 3000K para destacar visualmente la fractura central.

¿Qué altura tiene el FRACTURA® Class?

La altura de referencia del diseño es de 1,80 metros. Al tratarse de una fabricación a medida, pueden consultarse otras configuraciones según el proyecto.

¿Para qué medidas de cama se puede fabricar?

El diseño puede adaptarse a diferentes anchos, con referencias desde 1,40 m en adelante. También podemos evaluar medidas especiales para proyectos particulares.

¿La fractura cambia según el ancho?

Sí. Una de las características del concepto FRACTURA® Class es que la composición central adquiere mayor desarrollo visual a medida que aumenta el ancho del respaldo.

¿Qué tapizado utiliza?

La configuración principal utiliza pana premium. También pueden consultarse otras alternativas de tapizado según disponibilidad y proyecto.

¿Dónde se fabrica el FRACTURA® Class?

Se fabrica artesanalmente en Don Torcuato, Buenos Aires, y realizamos envíos a diferentes puntos de Argentina.

¿FRACTURA® Class es un diseño registrado?

Sí. El diseño FRACTURA corresponde al Modelo Industrial N.º 112746.
